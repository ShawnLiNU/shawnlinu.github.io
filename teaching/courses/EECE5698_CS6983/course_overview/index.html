Robot System Server

4 Credit Hours  ·  Graduate  ·  Cross-listed ECE & CS

Build the server that runs a fleet of robots in a real building, from simulated robots to physical TurtleBot 4s.

Team-driven and build-first. Six teams share one code base and ship a new version every two weeks, moving from simulation to real hardware. No course or textbook anywhere teaches this. Until now.

RobOrg  ·  ROS 2 Jazzy  ·  TurtleBot 4  ·  Nav2  ·  Gazebo  ·  Open-RMF compatible

Overview

Build something not taught anywhere else

What you will build

A working Robot System Server called RobOrg, with fleet management, multi-robot task allocation (MRTA), a map server, and traffic control. It starts with simulated robots in a simulated building and ends with real TurtleBot 4 robots moving in our lab, all run from one operator web page.

How the class works

Five two-week sprints, then a final integration period. Six teams each own one part of the server and work on their own Git branch. Every two weeks, the branches are merged into a new version of RobOrg. Each class starts with a lecture, followed by team reports and sprint planning.

Final System Deliverables

The class delivers a working Robot System Server:

  • RobOrg running simulated robots and real TurtleBot 4s in our lab from one operator web page
  • Three task assignment (MRTA) algorithms with a benchmarked comparison
  • A lab map built from the building's CAD drawings, with global path planning
  • Traffic control at hallways and doorways
  • Secure operator login and secure ROS 2 messaging

Why This Course

Six reasons to sign up

Unique in academia

No other university course or textbook teaches robot fleet server architecture.

Build, don't just study

Sprint-based teamwork in one shared code base. You ship working code every two weeks.

Open-RMF compatible

RobOrg speaks Open-RMF's messages and map formats, the framework used in hospitals and airports worldwide.

Real hardware

Progress from simulation to physical TurtleBot 4 robots in our campus building.

Publication potential

MRTA comparisons, fleet analytics, and maps from CAD drawings are publishable.

Lasting impact

Your server stays deployed for future NU robotics courses and research.
