Shortcuts and tips

  

    
F5 or Ctrl/Cmd+EnterRender

    
Ctrl/Cmd+SDownload the .scad file

    
Ctrl/Cmd+/Comment or uncomment selected lines

    
Tab / Shift+TabIndent or outdent

    
EscCancel a running render

    
MouseDrag to rotate, right drag to pan, scroll to zoom

  

  
Customizer: top level variables before the first module become controls. Use comments such as // [0:5:100] for a slider, // [a, b, c] for a menu, and /* [Group] */ for sections. Variables under /* [Hidden] */ stay hidden.

  
Libraries: add .scad library files in the Files tab so include <file.scad> and use <file.scad> can find them. STL, DXF, and SVG files there work with import().

  
Limits: text() needs fonts, which this web build may not include. Colors set with color() are not kept, because the model is shown as a single mesh. The rendering engine is OpenSCAD compiled to WebAssembly (about 14 MB, downloaded once and then cached by your browser).
